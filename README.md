# 小说接力控制台 · AUTO RC2

将现有 `333.zip` 十角色手动工作流中的交接动作自动化。三本小说分别推进，全局最多六个在途执行席位。使用普通 ChatGPT 网页及 GitHub；不使用 OpenAI API。

**交付性质：可安装的候选版本。已完成代码和本地故障测试，尚未用用户真实账号完成全流程验收。原 V4.3.2 APK 保持原样。**

执行载体：Windows 电脑＋Chrome / Edge 扩展。无需额外服务器、域名或Node安装。运行时电脑和浏览器要保持开启。手机使用本次新制作的安卓匹配生成器 1.0.0-RC2，支持本地保存与系统分享；也有离线HTML备用。APP可改学堂仓库与分支，生成的ZIP可直接导入新版电脑控制台。自动执行仍在电脑。

完整操作说明：[整合系统说明书与操作教程](docs/06_整合系统说明书与操作教程.md)。本版记录：[RC2构建与验收](docs/07_RC2构建与验收记录.md)。安卓APP和更新后的扩展一起使用；已有书不使用空仓库初始化来迁移学堂。

## 开始使用

1. 下载完整交付包，解压。
2. 在浏览器扩展页开启开发者模式，加载 `extension` 文件夹。
3. 打开扩展控制台，连接本仓库，填写GitHub令牌。
4. 每本书使用独立小说仓库和十个独立角色对话。控制台可生成匹配ZIP，也可直接初始化空小说仓库。
5. 先按[首次安装与试跑](docs/02_首次安装与试跑.md)完成一本短样书验收，再登记另外两本书。

学堂默认 **https://github.com/1464356758/xueyuan**，现在可在APP及控制台修改链接和学堂分支，并修正旧六平台决策器路径，按番茄、七猫、起点、豆瓣阅读各自入口取资料。只替换网址无法解决旧必读文件不存在的问题。

## 实现内容

- 三写手、双审核整组预留，成员均交有效完成凭证后才进入下一关；返修后的商业门禁和双审核也是整组。
- 文件存在不算完成；校验任务号、书号、随机标识、固定输入提交、产物提交、路径、SHA和字数。
- 业务完成由GitHub驱动，页面只发送任务及显示短ACK。正文不从页面抓取。
- 席位持续保留至已验凭证且对话被连续观察为空闲；未知状态保留席位。
- 发送前先保存状态。发送结果不明时不盲目重发；重启后从GitHub恢复。
- 总监负责匿名包、解封、返修令、记忆、LOCK和下一任务，调度器不代替创作裁决。
- 用户保留最终选题；账户限额、登录、验证码和无法判定的异常会暂停。
